# Aurona Code 0.4.15 Development Notes

0.4.15 is the active development line after the 0.4.14 Stable release. It focuses on restoring daily workflows and making dynamic extension and Agent operations observable without weakening the existing native authorization boundaries.

## Implemented In This Checkout

- Workspace trust checks run after the workbench mounts; requests discovered during startup are replayed to the mounted language modal.
- DevTools shortcuts and menu execution are available again, with a user-visible failure message when the native command cannot open.
- Account avatars fall back to initials after a failed restricted image request, including when the account changes.
- Marketplace downloads emit Rust progress events to the UI and expose a local `.aurx` picker backed by a one-time artifact handle.
- Remote extension installation remains fail-closed for missing, expired, mismatched or invalid signatures and signed catalogs. The UI reports those failures as a paused remote installation rather than a generic error.
- Agent context budgeting is 128K tokens. Message aggregation is immutable and task-scoped, and file, multi-file edit, Git, terminal and test tools carry explicit effects and confirmation metadata.
- Agent tool calls carry a workspace id, root and backend generation snapshot. A workspace change during checkpointing or approval discards the stale checkpoint and skips execution.
- `apply_diff` preflights all replacements against in-memory file versions, applies grouped edits with expected revisions, and attempts reverse-order rollback when a later file fails.
- `run_tests` waits for a shell completion marker, returns bounded output and the exit code, and reports non-zero test exits as tool failures instead of claiming that a command was merely queued.
- Shared Checkbox, Radio, Tabs, Table, Progress, Breadcrumb and VirtualList components are available to feature surfaces.

## Evidence Boundary

Targeted Agent and terminal tests pass after these changes, TypeScript plus scoped Biome checks are green, and the full frontend run completed with 109 test files and 419 tests passing. The full acceptance audit is still open: `Docs/0.4.15-Carryover-Plan.md` retains 47 in-progress items and 3 external-blocked prerequisites, and strict i18n still reports 92 hard-coded-string warnings. Rust validation is blocked in this checkout because the Windows MSVC toolchain (`cl.exe`) is not installed. Production Marketplace signatures, signed catalogs and release publication are external prerequisites; this development line does not claim those artifacts exist.
