# Aurona Code 0.3.3 Release Notes

Aurona Code 0.3.3 focuses on visible language intelligence and the first real
debugging workflow.

## Language services

- Pyright and TypeScript Language Server are staged with a bundled Node runtime.
- Windows verbatim resource paths are normalized before they reach Node, so
  built-in Pyright can start from installation directories containing spaces
  and non-ASCII characters.
- Hover is an interactive editor surface with Markdown/code presentation,
  cancellation, and visible error states.
- Automatic completion can be disabled and manual completion is available with
  `Ctrl+Space`.
- Language settings expose server status, lifecycle actions, hover delay, and
  completion behavior.
- Language status and Problems now follow the active code tab. Existing,
  multi-line, and zero-width diagnostics render directly in the editor with
  severity-aware wave underlines.

## Debugging

- DAP transport and routing are independent from LSP JSON-RPC.
- Adapter requests have sequence IDs, timeouts, stderr capture, lifecycle state,
  and process-tree cleanup.
- Aurona detects supported workspaces and creates a selected
  `.aurona/launch.json` configuration automatically. The generated version
  `0.1.0` file remains editable.
- The Run and Debug sidebar shows real configurations, session state, call
  stack, variables, and manageable breakpoints in the shared sidebar page
  layout. The editor gutter can toggle breakpoints.
- Non-code pages use a focused empty state; supported configurations are
  selected by the active language and debugger lists use Aurona's native list
  surfaces.
- The sidebar and bottom panel can be resized from their separators. Layout
  sizes persist across restarts, with keyboard adjustment and double-click
  reset available.
- `F5` starts or continues debugging and `Shift+F5` stops the current session.
- Python debugging checks `debugpy` in the selected Python environment before
  launching. If it is missing, Aurona offers an explicit one-click installation
  into that environment and continues after successful verification.
- Terminal panes recalculate their viewport and repaint the xterm buffer after
  becoming visible, reducing intermittent missing text after panel switches.
- Run and Debug settings use the same static card and row language as the other
  settings pages, without row-wide hover highlighting.

## Scope

The plugin system remains deferred to 0.4.0. The former plugin placeholder is
not exposed in the 0.3.3 activity bar.
