# V0.4.14 Release Decision

On 2026-10-06 the maintainer explicitly requested: "正式发布，将剩余内容归结于下个版本的更新内容".

## Approved Scope

Publish 0.4.14 as a formal Stable release containing the current safety, stability and resource-management implementation. Carry the unfinished acceptance and external integration work into 0.4.15, preserving all 50 original IDs and evidence in [Implementation Status](0.4.14-Implementation-Status.md) and [Carryover Plan](0.4.15-Carryover-Plan.md).

The matrix remains 47 in-progress, three external-blocked and zero fully verified. This decision changes the release scope; it does not certify native workflows, fault injection, complete performance comparisons, production Marketplace descriptors/catalogs or updater key provenance. Unsigned Marketplace packages remain blocked by the client. Existing custom-service and local-tool approval rules remain enforced.

## Mandatory Publication Checks

The tagged commit must have a successful seven-job Quality run. Rebuild all three platform installers from that commit; the previous unsigned local installer is historical evidence only. Verify updater artifacts and supplemental DMG/DEB installers against the public key pinned in trusted source, including version, Stable channel, size and SHA-256. Verify signed release metadata before constructing latest.json. Wrong keys, altered bytes, changed endpoints or mixed channels still fail publication.

`check:audit:release` validates the approved scope, exact carryover coverage and documents. `check:audit:complete` preserves the original full-closure gate and remains expected to fail until complete evidence exists. Neither command alone certifies installer authenticity: the Release workflow separately verifies real production-key signatures before upload and publication.

Tag construction, build, draft upload and publication are separate actions. Only the approved 0.4.14 Stable release is promoted; Pioneer is unchanged. Published artifacts and CI links are recorded in [Release Preflight](0.4.14-Release-Preflight.md).
