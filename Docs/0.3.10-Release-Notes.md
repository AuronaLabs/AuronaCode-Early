# Aurona Code 0.3.10 — 舒适性

> 0.3.9 让用户第一次「能找到」能力；0.3.10 让用户第一次「能连续地使用」这些能力。
> 本版本以大规模检测与收口为主：把编辑、语言服务、调试、搜索、设置、账户和工作台连接成完整、可靠、舒服的日常开发体验。

## 更舒服的代码智能

- 跳转有历史：Definition / References / 符号与内容跳转自动记录，Alt+← / Alt+→ 后退前进。
- 多结果不再武断打开第一个：Definition 多结果与 References 共用统一结果视图（文件分组、数量、行预览、命中高亮、键盘导航、Enter 跳转、Esc 关闭）。
- Rename 全流程：F2 → 输入新名称 → 预览「12 files · 37 changes」（含每处原文/新文）→ 确认/取消；应用前版本校验，Ctrl+Z 可整体回退。
- Code Actions 进编辑器：Ctrl+. 唤起，带 WorkspaceEdit 的操作必须先预览再应用；Problems 行悬停直接快速修复。
- WorkspaceEdit 成为共享能力：Rename、Code Action 与未来重构共用同一套多文件修改预览。
- Completion 更聪明：按需 resolve 文档/详情、stale 取消、TextEdit/AdditionalTextEdits 应用后编辑器与 LSP 状态同步。
- Symbols 体系：Ctrl/Cmd+Shift+O 当前文件符号搜索 + 活动栏 Outline 大纲侧边栏，共享同一符号拍平模型。
- Hover 收口：延迟、取消、过期丢弃、滚动关闭、视口夹紧、Markdown/代码块渲染。
- Problems 生命周期：文件删除/重命名/关闭/切换工作区/LSP 重启时诊断正确清理，重启后自动重开文档恢复诊断。

## 更完整的调试体验

- 线程视图与切换：暂停后显示全部线程，切换联动调用栈与变量。
- 调用栈 / 变量：帧选择、懒展开、大对象分页（100 条/页 + 加载更多）、复制值/表达式、暂停间变更高亮。
- Watch 与 Debug Console：监视表达式暂停自动刷新；控制台支持 DAP Evaluate 与 ↑↓ 历史。
- 断点管理：已验证/未验证/已禁用状态、Adapter message、单个切换、全部启用/禁用、移除全部；支持条件断点、命中条件与日志点。
- 工具栏按会话状态正确启用：继续/暂停/单步跳过/进入/跳出/重启/停止；异常退出回到 idle，不留死状态。

## Fliuno 与设置继续完善

- 键盘导航回归修复（↑↓ / PageUp / PageDown / Home / End + 自动保持可见）。
- 文件索引随 `fs:changed` 实时刷新；Prefix 与 Scope 切换统一；渲染顺序=键盘顺序=执行顺序。
- Regex 内容搜索不再被二次 fuzzy 过滤；同义词回到生产路径；旧全局搜索体系正式下线。
- 设置搜索直达具体项（Section → Setting → Scroll → Highlight）；设置九大分类；单项一键重置。
- Settings Registry 成为设置搜索与 Fliuno Settings Provider 的共同数据源，明确 Preference / Action / Navigation 边界。
- 命令与界面国际化机制：Command Registry 支持 titleKey/categoryKey，Fliuno 命令随语言切换；关键界面文案全部进入语言包。

- 异步生命周期：LSP / Fliuno / Debug 全部带 stale 守卫与取消；组件与服务卸载时清理监听与定时器。
