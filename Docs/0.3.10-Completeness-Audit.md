# Aurona Code 0.3.10 Product Completeness Audit

> 审计方式：以当前工作区源码、命令注册表、EventBus 契约、测试与构建结果为证据，逐项核对功能可达性、重复入口、死 UI、命令路径、异步生命周期、错误处理、状态恢复、资源生命周期、跨平台与布局显示。审计过程同步修复已证实的问题，未证实的候选只记录、不臆改。

## A. 功能可达性

方法：枚举真实功能并核对入口（菜单 / 按钮 / 快捷键 / Fliuno / 右键菜单 / 命令注册）。

| 功能 | 入口证据 |
| --- | --- |
| 文件打开/新建/保存 | 顶部菜单 + `workbench.action.files.*`（Ctrl+O / Ctrl+N / Ctrl+S）|
| 编辑（撤销/重做/复制等） | 菜单 + `editor.action.*` |
| 语言服务（定义/引用/重命名/格式化/符号） | 命令（F12 / Shift+F12 / F2 / Ctrl+. / Ctrl+Shift+O）+ Fliuno 符号 Provider |
| 运行与调试 | 活动栏「运行和调试」+ F5 命令 + Fliuno 命令 |
| 终端 | 底部面板 + `workbench.action.terminal.toggleTerminal` |
| 设置 | 活动栏齿轮 + `workbench.action.openSettings` + Fliuno Settings Provider |
| Fliuno | 活动栏入口、标题栏按钮、Ctrl+Shift+P |
| 性能测试 / 更新记录 / 关于 | 帮助菜单 + `workbench.action.openPerformance/openChangelog/openAbout` |
| 源代码管理 | 活动栏侧边栏 |
| 通知 | 活动栏侧边栏 |
| Aurona 账户 | 状态栏头像 + 设置「Aurona 账户」+ `account.*` 命令 |
| 导航历史 | Alt+← / Alt+→ 命令 |

结论：所有真实功能均有至少一个合理入口，未发现「功能存在但无入口」。

## B. 重复入口

- Legacy 全局搜索已删除（SearchPanel、SIDEBAR_SEARCH、旧持久化迁移），不再存在“两套搜索 UI”。
- Fliuno Quick 与 Workspace 共用 `FliunoCore` + `FliunoSearchSession`，搜索逻辑唯一。
- 设置搜索与 Fliuno Settings Provider 共用 `settings:reveal` 导航契约。
- 结果展示（Definitions / References）共用 `LocationResultsStore` + 底部「引用」面板。
- 已知并行但非重复：DebugPanel 内开始/停止按钮与 `workbench.action.debug.start/stop` 命令并存，属于面板本地控制面，不构成第二套功能实现。

结论：未发现“两个 UI 做完全相同事情”的重复实现。

## C. Dead UI

本轮实际删除：

- `Src/Features/Search/SearchPanel.tsx`（已废弃全局搜索 UI）
- `Src/UI/Fliuno/FliunoSearch.ts` 与旧测试（生产搜索迁移后的兼容层死代码）
- `SIDEBAR_SEARCH`、`SIDEBAR_PLUGINS`（未使用的常量；插件体系按版本规划推迟到 0.4.0）
- Workspace 侧边栏中 Legacy Search 渲染分支与懒加载

核查未发现 no-op onClick（`onClick={() => {}}`）等假按钮。设置页「代码缩略图」标注「暂不可用」并给出原因，属于诚实占位而非假按钮；高级页实验性区域显示明确的「即将开放」文案。

## D. Command Registry 完整性

- 核心用户动作均注册稳定 Command ID（文件/编辑/语言服务/调试/视图/终端/运行/工作台/帮助/开发者/导航/账户/Fliuno）。
- 顶部菜单、活动栏、Fliuno 执行均走 `CommandRegistry.execute`，未发现各自直连逻辑的分叉实现。
- 快捷键：Ctrl+O/N/S、F5、F12、Shift+F12、F2、Ctrl+.、Ctrl+Shift+O、Ctrl+Shift+P、Alt+←/→、Ctrl+Space 均已注册。
- Command metadata 支持 `titleKey/categoryKey`，Fliuno 展示随语言切换。

遗留（记录，不阻塞）：TitleBar 菜单文案、侧边栏 `SIDEBAR_*` 显示名、`disabledReason` 仍为硬编码中文，后续在 i18n 收口批次处理。

## E. 异步生命周期

- LSP Hover / Completion / Location Results / Diagnostics：全部有 requestId/generation 守卫与过期丢弃；滚动即关闭 Hover，内容变化拒绝旧补全。
- Fliuno：`FliunoSearchSession` 过期代次 + `WorkspaceSearchIPC.cancel`；Quick/Workspace 卸载时清理 timer 与 session。
- Debug：`selectFrame` / `loadVariables` / `evaluateWatch` 带会话与帧守卫；线程切换后旧帧数据不会串场。
- 诊断生命周期：文件删除/重命名/关闭标签/切换工作区/LSP 停止与重启均正确清理；重启后重新 didOpen 已打开文档。

## F. 错误处理

- 调试启动失败 → `failed` 状态 + 面板错误展示 + 日志；求值/监视失败 → 明确错误文本。
- Rename / Code Action：应用前版本校验，失败在预览模态内反馈，不丢数据。
- 终端启动失败、Fliuno 文件索引失败、Git 操作失败均有可见反馈（面板或 Toast）。
- 未发现“用户动作失败但只 console.error”的主路径。

## G. 状态恢复

- 工作区：tabs / activeTab / sidebar / 底部面板高度持久化并恢复。
- 语言：`aurona.locale` 持久化；主题/密度/编辑器偏好走 user-config。
- 账户：启动时 `AccountService.initialize()` 恢复会话。
- 兼容：旧 `activeSidebar === "全局搜索"` 自动迁移为 null。
- 断点与 Watch 为会话级状态，不持久化（符合调试语义）。

## H. 资源生命周期

- 应用关闭：`RecoveryCoordinator.flushAll → DocumentService.closeAll → LspClient.shutdownCurrent → AccountService.shutdown → destroy`。
- `AppServices.dispose`：拆除 workbench/terminal/editor 存储（terminal dispose 停 PTY），新增 `DebugService.dispose()`。
- EventBus 订阅均返回 unsubscribe 并在组件/服务清理时调用。

## I. 跨平台

- CI：release workflow 三平台矩阵（macOS universal / Ubuntu / Windows）已在预检通过后执行。
- 代码级：PlatformService 提供平台分支；shell 选择、换行与扩展名逻辑存在。
- 已知债务（记录）：`UriUtils` 的路径转换以 Windows 反斜杠为主，macOS/Linux 上 file URI 往返需要平台化路径处理；列入后续 P2，需真实平台验证。

## J. 布局与显示

- `prefers-reduced-motion` 已覆盖（Theme.css / Splash.css），流光等动效尊重系统设置。
- 界面密度（compact/regular/comfortable）随窗口尺寸与配置生效。
- 主题/浅深色统一走 Material token；本轮顺手修复编辑器搜索框的 legacy `gray-*` 色值。
- 200% 缩放、多主题人工矩阵：属于发布前人工验证清单，未自动化（见发布标准）。

## 审计结论

本轮审计修复：删除 Legacy Search 与两个未用常量、修复编辑器搜索框文案/色值、补齐 DebugService 关闭清理。
未发现新的高危数据丢失、stuck loading 或 orphan 主路径；已知遗留均以「记录 + 后续批次」形式保留。

## 附录：编辑器舒适度检查

方法：逐项核对 AuronaEngine 的光标/选区/IME/剪贴板/搜索实现与对应测试。

- 光标：Left/Right/Up/Down/Home/End、Ctrl+单词移动、grapheme 边界（CJK/Emoji）、空行与超长行均有实现；Shift 组合选择有效。
- IME：composition start/update/end 全链路存在，组合期间输入与快捷键被 gate，结束后落盘并触发补全。
- 剪贴板：copy/cut/paste 支持选区与整行语义，粘贴统一归一化 CRLF/CR → LF。
- 撤销/重做：typing 合并、paste/delete/completion 进入历史；本版本补齐 WorkspaceEdit 也进入撤销历史。
- 搜索：编辑器内 Find 支持大小写不敏感与前后导航；Match Case / Regex / Replace 未实现且 UI 未假装存在（诚实子集）。
- 文件生命周期：New/Open/Save/Close/Dirty/Rename/Delete 均有路径；Save As 与外部磁盘变更未实现，已在遗留记录中注明，且不会静默覆盖（保存前有同步错误保护）。

### 本次检查发现并修复

- 问题：`DocumentService.subscribe` 无任何订阅者，Rename / Code Action 应用 WorkspaceEdit 后，打开中的编辑器视图不更新、撤销历史不包含该修改。
- 修复：EditorTab 订阅文档变更并把外部内容转发给 AuronaEngine；引擎应用内容时写入撤销历史（Ctrl+Z 可回退），并做行列夹紧；非打开文件不受影响。
- 测试：新增 EditorTab 外部编辑同步用例（模拟 WorkspaceEdit 应用后视图收到新内容）。

## 附录：终端舒适度检查

方法：核对 TerminalService / TerminalView / useTerminalStore 生命周期。

- startup：创建 readiness 状态机，10 秒超时，失败状态在视图中显示错误覆盖层。
- shell：`getAvailableShells` 缓存探测结果；无 shell 时回退默认。
- 多终端 / 切换 / 重命名 / 关闭：列表、active 事件、PTY close 均完整。
- 输入输出：write/executeCommand/clear；Ctrl+C 由 PTY 处理；Unicode/中文透传。
- 进程退出：TerminalView 监听 exited 状态；应用关闭时 `dispose()` 对全部 PTY 执行 close，无 orphan。
- 已知记录：显式「重启终端」按钮未实现，用关闭+新建替代（P2）。

## 附录：Git 日常使用检查

方法：核对 SourceControl 的状态加载、操作与错误反馈。

- 状态：加载中、失败均有状态（statusError 内联展示 + Toast）；has_remote / detached 等状态字段已跟踪。
- 操作：暂存/取消/提交/分支/拉取推送/放弃修改均有独立错误反馈（Toast + OutputService），网络/凭据失败可见。
- 工作区切换：监听 `workspace:root-changed` 自动刷新仓库状态。
- 已知记录：detached HEAD 与 credentials 失败依赖 Git 返回文本，展示为原始错误信息；后续可做错误文案归一化。

## 附录：性能要求核对

- 启动：AppBootstrapper 异步初始化服务；Settings Registry 为轻量 Map，i18n 仅 localStorage 读取，Fliuno 懒加载文件索引，LSP 按需启动。
- Fliuno：输入 100–120ms debounce + 请求取消；结果上限 120，避免大列表。
- 编辑器：虚拟滚动 + 大文件模式；输入路径无新增同步初始化。
- Diagnostics：本轮新增 Problems 面板渲染上限（500 条 + 截断提示），大量诊断不再拖垮 UI。
- References/Symbols：结果有 limit；变量树懒展开，不一次渲染大对象。

## 附录：DAP 舒适度补充

- 条件断点 / 命中条件 / 日志点：断点行可编辑三字段，同步时按 DAP 规范发送 condition / hitCondition / logMessage；禁用项不发送。
- 变量变更高亮：暂停时对上一轮变量快照做 diff，本轮新增或变化的值以琥珀色标注。
- 以上均带会话/帧守卫，并有单测覆盖（条件/命中/日志字段序列化、变量 diff）。
