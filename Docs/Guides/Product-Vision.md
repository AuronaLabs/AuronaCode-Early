# 产品方向

**Aurona Code · 创造无限可能**

*Create Without Limits.*

我们希望开发工具更自然地融入思考：打开项目、阅读代码、尝试修改，再把想法一步步变成现实。好的工作台应当清楚、顺手，让人愿意长时间使用。

## 为创作留出空间

Aurona Code 把代码编辑、文件浏览、搜索、Git、终端、语言服务、调试和扩展放在同一工作空间。功能围绕实际任务协作，常用操作有清晰入口，反馈也能帮助使用者继续前进。

AI Assistant 是这个工作台的一部分。对话提供思路，Agent 操作保持可审阅、可取消，并在支持的范围内提供恢复记录。是否启用远程服务、选择哪个服务，以及授予哪些能力，都应让使用者知情选择。

## 当前版本的重点

0.4.18「稳」聚焦模块边界、运行稳定性与维护一致性：

- 让工作区、文档、Git、扩展和终端的状态更新各有明确归属。
- 用领域边界和资源生命周期管理控制改动影响范围。
- 让配置写入结果与应用行为保持一致，并保留清楚的安全选项。
- 以克制的材质、清楚的层次和适量的反馈服务内容。
- 如实说明兼容范围、自动化结果与尚未覆盖的桌面体验。

## 如何判断一次改进

一次改进应当能回答：解决了谁的问题，减少了什么操作或困惑，出现异常时能否理解并恢复，后续维护者能否找到边界与证据。
