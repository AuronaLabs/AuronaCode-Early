# 产品方向

**Aurona Code · 创造永无止境**

*Create Without Limits.*

Aurona Code 把编辑、文件浏览、搜索、Git、终端、语言服务、调试、扩展和 AI 放进同一个桌面工作台，让阅读代码、尝试修改和验证想法更连贯。

## 当前阶段

0.5.0 Alpha1 是全新升级的过渡版本。本阶段先精简入口、统一排版、打磨基础交互，并修复使用中暴露的问题，为后续整体升级建立基础。

账号体系和在线扩展商店暂时移除，扩展通过本地包导入。AI 服务继续由使用者自行配置。后续能力会重新规划，当前精简不代表产品长期只提供本地功能。

## 体验标准

- 常用操作容易找到，相关动作集中呈现，减少不必要的按钮和重复页面。
- 编辑内容与任务结果优先，材质、图标和动态效果保持克制。
- 运行状态清楚，长任务可以取消，失败有明确反馈。
- AI 改动可以审阅，在支持的文件范围内提供恢复，并保留用户配置的权限边界。
- 模块和状态有明确归属，让新能力可以持续迭代。

一次改进需要说明解决了什么问题、减少了哪些操作、如何处理失败，以及验证覆盖到哪里。
