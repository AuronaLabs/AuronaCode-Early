扩展包签名、运行权限和资源预算是不同的策略。认证选项由用户配置，能力边界仍需按实际宿主契约处理，详见[安全与信任](../Security-and-Trust.md)。

发布说明应列出实际测试的宿主版本、平台和使用场景。接口存在或编译通过，不代表任意第三方扩展已经兼容。
