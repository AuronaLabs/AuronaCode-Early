# Aurona Code 架构设计与系统概览

Aurona Code 是一款基于 **Tauri 2 + React 19 + Rust** 构建的现代化轻量级桌面代码编辑器。它放弃了传统 Electron / Monaco 的重型依赖路径，采用自研编辑器引擎（AuronaEngine）结合 Rust 高性能文本绳（Ropey），并以 WebAssembly Component Model (WASI P2) 构建了高安全沙箱的插件底座。

## 2. 前端架构分层与解耦治理

为了保证代码库的可维护性与高内聚，Aurona Code 将传统庞大的前端组件进行了系统性解耦：

### 2.1 核心编辑器引擎 (`AuronaEngine`)
- **自动补全子系统 (`useEditorAutocomplete`)**：负责 LSP Completion 请求防抖、前缀匹配打分、键盘选择与光标插入；
- **选区与文本操作 (`useEditorSelectionOps`)**：负责多行/单行选区删除、单词边界扫描、UTF-16 偏移与行列转换；
- **快捷键分发器 (`useEditorKeybindings`)**：管理代码缩进/反缩进、单行/块注释切换、行复制/移动、成对括号回车与退格对齐；
- **主渲染引擎 (`AuronaEngine`)**：体积精简 62.9%，专注虚拟滚动视口与 DOM 渲染。

### 2.2 主工作区与弹窗系统 (`WorkspaceView`)
- **布局调度 (`WorkspaceView`)**：负责左右栅格、拖拽把柄（PanelResizeHandle）与活动侧边栏；
- **语言服务模态集中点 (`LanguageModals`)**：统一管理符号重命名、Code Action 列表与差异预览、文档符号检索以及工作区信任；
- **底部面板调度 (`WorkspaceBottomPanel`)**：统一管理多 Shell 终端、日志输出通道、Debug REPL 控制台、多作用域问题诊断与引用列表。

### 2.3 设置中心 (`SettingsTab`)
- 拆分为通用设置 (`GeneralSettingsSection`)、编辑器设置 (`EditorSettingsSection`)、版本控制设置 (`SourceControlSettingsSection`) 与高级维护设置 (`AdvancedSettingsSection`)；
- 配合 `SettingRegistry` 提供分词搜索与导航结果实时徽章指示。

## 3. WASM 扩展沙箱与 AURX 规范

- **Wasmtime 47.x 强隔离**：扩展编译为 `wasm32-wasip2` 组件，运行在完全受控的 WASM 虚拟机中；
- **Linker 预编译缓存**：初始化时预缓存 WASM Linker，启用速度优化等级，冷启动与渲染极其迅速；
- **官方内置三大扩展矩阵**：
  1. **`aurona.markdown` (Markdown 实时预览)**：绑定编辑器流式解析渲染；
  2. **`aurona.planner` (任务与测试看板)**：独立运行，集成 Tabler 矢量图标 SDK，工作区安全持久化；
  3. **`aurona.vscode-compat` (VSCode 兼容转译层)**：提供核心 VSCode API 模拟与 Node.js 安全沙箱；
- **多层安全防线**：
  - **Fuel 燃料消耗上限**：防范插件内部无限死循环；
  - **Memory 内存限制**：严格限制单个插件的线性内存上限；
  - **安全文件读写**：强制校验工作区根路径，拦截 `..` 路径逃逸与 `.git` 敏感系统目录。

---

## 4. 语言服务 (LSP) 与集成终端

- **统一轻量语言服务**：内置对 Python 与 TypeScript 的 LSP 进程管理、诊断收集与智能补全；
- **无背景卡片终端**：集成 `xterm.js` 与 `portable-pty`，启用透明渲染并完美融入拟物背景。
