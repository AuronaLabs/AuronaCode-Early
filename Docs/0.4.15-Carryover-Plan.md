# V0.4.15 Carryover Plan

## Priority and Acceptance

Complete P0 production provenance and native workflow evidence first, then P1 security/fault workflows, P2 lifecycle/performance and P3 recovery/resource evidence. The 47 in-progress items and three external-blocked items retain their original acceptance criteria. Never change them to verified without evidence. Marketplace integration requires production signed package descriptors and catalogs from its separate service; unsigned remote installation remains blocked. Compare optimized installers against the fixed performance baseline and preserve the original negative tests and quotas.
