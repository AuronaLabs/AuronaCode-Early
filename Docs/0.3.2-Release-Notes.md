# Aurona Code 0.3.2 Release Notes

Aurona Code 0.3.2 focuses on architecture and language-service reliability.
It introduces application-level document, workspace, diagnostics, output, and
language-feature services; replaces the previous LSP transport and lifecycle;
and connects P0 language features to the existing custom editor.

## Delivered in source

- Unified document revisions for editor persistence and LSP synchronization.
- Runtime workspace descriptor with a future-compatible roots model.
- Bounded, redacted Output channels and workspace-wide diagnostics storage.
- Streaming Content-Length decoding and JSON-RPC request routing.
- Language-server state, capabilities, stderr, cancellation, timeout, shutdown,
  restart, and management commands.
- Diagnostics, completion, hover, definition, references, document symbols,
  rename preview, formatting, and code-action UI paths.
- Workspace language-service configuration and explicit workspace trust.
- Bundled development dependency for TypeScript Language Server integration.

## Verification status

Frontend type checking and automated tests are required release gates. Rust
tests, Tauri packaging, real TypeScript Language Server end-to-end behavior,
performance comparison, and process-tree cleanup remain release-blocking until
the Windows MSVC C++ Build Tools environment is available.

DAP and plugins are not part of the completed 0.3.2 feature set.
