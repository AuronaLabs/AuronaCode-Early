# Aurona Code 0.4.18「稳」

**发布于 2026 年 11 月 7 日 · Stable**

Aurona Code 0.4.18 聚焦架构边界与运行稳定性。随着工作台能力不断增加，本版重新整理模块职责、状态归属和资源生命周期，并修复跨工作区、编辑保存、Git、扩展及终端流程中的异步问题。

[下载 0.4.18](https://github.com/AuronaLabs/AuronaCode-Early/releases/tag/v0.4.18) · [文档首页](../../README.md)

## 架构与维护

- 按职责整理 TypeScript 工作区、文档、Git、调试、命令、扩展和工作台模块，分离领域服务、应用装配与界面状态绑定。
- 将 Rust 工作区、文件系统、Git、编辑器和扩展运行时拆分为领域模块，保留现有 IPC 命令与权限检查边界。
- 分离扩展市场的网络传输、数据模型与安装流程，明确 SDK 宿主端口和扩展会话的资源所有权。
- 将模块依赖、循环引用、Rust 领域入口和 Markdown 文档质量检查纳入工程验证。

## 稳定性改进

- 工作区切换通过会话代次隔离旧授权、查询和初始化结果，避免旧项目状态写入新工作区。
- 文档编辑、保存和关闭按路径协调；语言服务延迟不阻塞基础保存，保存确认后重新检查修改状态。
- Git 查询共享缓存与写后刷新规则；旧仓库结果、迟到回调和重复写操作不再覆盖当前状态。
- 扩展停用或宿主退出时使旧请求失效，并回收命令、事件、视图和桥接资源。
- 配置写入按最近一次成功状态合并；关键持久化失败会进入关闭检查并保留重试机会。
- 终端会话隔离迟到的 Shell、PTY 输出与退出事件；清理监听和计时器，并改进命令结束标记及 UTF-8 分块解码。

## 设置与主题

安全配置仍提供独立选项，插件包和目录签名验证默认开启；应用更新认证使用独立信任链。插件视图使用统一主题快照，Markdown 主体保持透明，减少与外层材质叠加。

## 兼容范围与验证

VS Code 兼容层继续仅支持已实现并列明的 API，不承诺完整 VS Code 或 Node.js 兼容。自动化测试、真实桌面交互、系统缩放与输入法验收属于不同层次；本版未据自动化结果宣称性能提升比例，也未将尚未执行的桌面验收写成通过。详见[本版交付记录](../../Development/0.4.18/Acceptance-Report.md)及[现有兼容能力矩阵](../0.4.17/VSCode-Compatibility-Matrix.md)。
