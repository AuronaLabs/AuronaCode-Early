# Aurona Code 产品方向

Aurona Code 面向需要本地编辑、检查和调试代码的开发者。自研编辑器、项目检索、Git、终端和扩展服务于同一个工作台；AI Assistant 的修改应当可审阅、可取消，并在条件允许时恢复。

0.4.14 优先处理安全边界、数据保护和资源消耗。50 项审计工作的范围以 [当前计划](0.4.14-Audit-Plan.md)为准，完成情况以 [状态矩阵](0.4.14-Implementation-Status.md)为准。

Smart Capsule 0.5 等后续设计位于 [Roadmap](Roadmap/README.md)，不构成本版功能承诺。以往版本的愿景和里程碑保存在 [Archive](Archive/Product-Vision-Legacy-0.4.13.md)。
