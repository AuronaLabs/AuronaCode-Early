## Phase 1 — 联网技术调研

**Status: 完成**

完整结论见 [Docs/V0.3.12-Extension-Research.md](V0.3.12-Extension-Research.md)。核心决策：

1. WASI P3 宿主面不用于本阶段；使用 Component Model + 自定义 `aurona:*` WIT；
2. Wasmtime 47.0.3（含最新安全修复）；
3. Guest 使用 `wasm32-wasip2` target + `wit-bindgen` 直接产出 Component；
4. AURX 为 ZIP-compatible，`zip 8.6.0` 逐 entry 安全校验，不落地解压；
5. Markdown 解析与消毒全部在 guest（pulldown-cmark 0.13.4 + ammonia >= 4.1.4）；
6. 插件 UI 使用 sandbox iframe srcdoc + 结构化 postMessage，不放开主 CSP；
7. 仅 `editor.current.read`、`workspace.read` 两个权限，Rust 侧二次校验。

## 回归修复（实机反馈后）

**Status: 完成**

用户实机反馈四个问题，均已修复：

1. **插件视图黑色背景**：`srcdoc` 文档里的 `color-scheme: light dark` 在深色模式下把 iframe 画布渲染成不透明黑色（Edge headless 实证：dark → rgb(18,18,18)，plain → 透明）。已移除 `color-scheme`，`html/body` 显式 `background: transparent`，卡片背景可直接透出。
2. **预览不动态更新**：主窗口 CSP `script-src 'self'` 会被 srcdoc 继承，把插件 UI 的内联脚本全部拦截（Edge headless 实证：CSP 下 `not-run`，无 CSP `ran`）。V1 改为**宿主组装**：`ExtensionViewHost` 把渲染结果直接注入模板的 `<!--AURONA_RENDER_SLOT-->`，随每次渲染重建 `srcdoc`；iframe 无脚本（`sandbox=""`），CSP 与隔离不变。postMessage 桥与 view-ready 标记移除，插件 UI 的 JS 交互能力记录为 V1 limitation。
3. **新增「扩展」侧边栏**：Activity Bar 内置 `扩展` 入口（`SIDEBAR_EXTENSIONS`），`ExtensionsPanel` 列出已发现扩展（图标/名称/版本/内置标签）并提供「打开」按钮跳转插件视图；三语 i18n 已补齐。
4. **Markdown 图标颜色**：SVG 图标原用 `stroke="currentColor"`，在 `<img>` 上下文中解析为黑色；改为固定 `#4f8cff`，深浅色下均可见。

验证：typecheck / biome / boundaries / materials / 169 项前端测试 / 生产构建 / AURX 校验 / Rust 扩展 runtime 8 项测试全部通过。

## 回归修复 2（实机反馈定位根因）

**Status: 完成**

1. **预览完全不渲染（根因）**：Tauri 命令对结构体参数要求 JS payload 用参数名包一层（对照既有 `dap_start({ launch })` 约定）；此前 `extensions_render` 把字段平铺传递，`request` 参数缺失导致每次渲染命令都失败。已改为 `invokeDesktop("extensions_render", { request })`，并新增 [ExtensionCommands.test.ts](Src/Foundation/IPC/ExtensionCommands.test.ts) 锁定 payload 形状防回归。
2. **插件显示区域白色**：WebView2 中 iframe 透明背景在毛玻璃卡片上合成出白色（Edge 红底测试无法复现该场景）。改为插件模板显式主题背景：light `#f7f8fb` / dark `#16171c`，与卡片观感一致，不再依赖透明合成。
3. **右侧编辑器黑色**：编辑器根节点 `[data-editor-font]` 一直使用 `--EditorSurface` 深色安静区背景（dark 下 `rgba(9,12,18,0.68)`），盖住了卡片。按用户要求改为 `transparent`，编辑器直接透出 Card 的 `--material-panel` 背景。

验证：typecheck / biome / boundaries / materials / 171 项前端测试（新增 2 项 IPC 回归）/ 生产构建 / AURX 校验 / Rust 扩展 27 项测试全部通过。
