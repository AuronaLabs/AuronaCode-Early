# V0.4.14 Audit Plan

All 50 accepted P0-P3 audit items are in this single 0.4.x milestone. Scope is Aurona Code only: frontend, Rust, built-in packages, scripts, CI and documentation. Preserve explicitly authorized custom AI providers, local LSP/DAP/interpreters, external initial terminal directories and local extensions.

Release scope amendment, 2026-10-06: the maintainer approved formal 0.4.14 publication and moved unfinished acceptance/external integration to [0.4.15](0.4.15-Carryover-Plan.md). The original acceptance criteria below remain the full-closure standard, not a claim that they passed. See [Release Decision](0.4.14-Release-Decision.md).

## Delivery Order

1. Backend scopes, generations, authorization, bounded resources and four P0 protections.
2. File/Git/process/download/extension/AI/Agent safety with IPC negative tests.
3. Bounded pagination, cancellation, lifecycle, concurrency, caches and recovery.
4. Full quality checks, three-platform Rust checks, real desktop acceptance, local candidate artifacts and signing verification.

## Shared Contracts

Baseline: `main / 874e532 / V0.4.13`. Rust owns canonical workspace roots, capability directory handles and generations. Caller-supplied roots never authorize access. Session grants bind caller, operation, resource and configuration fingerprint, and expire on workspace switch/restart/configuration change. Dangerous confirmation lasts 60 seconds and is consumed once. Preserve native authorization for external files/repositories/cwd and local tools.

LSP/DAP/Python use launch registry IDs. AI IPC uses profile IDs and keyring credentials. Packages cross IPC as artifact IDs. Directory pages carry cursor/generation; Marketplace uses independent task IDs. Agent commands require explicit allow-list/effects metadata. Errors retain diagnostic codes and redact secrets. Detailed implementation/validation gaps are tracked in [Implementation Status](0.4.14-Implementation-Status.md).

## Validation Sequence

Run `pnpm run quality:full`, targeted IPC/security/migration/fault/stress suites and Windows/macOS/Linux Rust CI. Windows initializes VS2022 vcvars64/vcvars32. Product text covers six locales. Fixtures do not replace real signatures, WebView behavior or resource measurement.

Fault tests include keyring unavailable, disk full, wrong wheel hash, process timeout, nth-file restore failure, crash during restore, stale generation and SSE EOF. Record hardware/OS/WebView version and before/after p50/p95/RSS/thread/process/event/I/O evidence. Unexplained interaction p95 regression above 10% blocks acceptance. No release freeze date is assigned until all required evidence is collected.

## Acceptance

Every ID in `scripts/data/audit-0.4.14.json` needs implementation, relevant regression tests and actual validation evidence. Exercise malformed paths, junction/symlink replacement, forged approval, revoked generation, endpoint redirects, malicious markup, archive bombs, altered signatures, quota overflow and cancellation. Repeat lifecycle tests 100 times and watcher storms 100,000 times. Record p50/p95, RSS, events, threads, children and I/O on a fixed baseline. Interactive p95 regressions above 10% require investigation. Stop/abort must reclaim managed requests and processes within two seconds.

Historical storage traversal, uninstall traversal, dirty-tab close, dismissed approvals, Unicode cursor and denied-extension-read regressions remain in the suite.

## Release Boundary

The original milestone permitted local candidates only. The 2026-10-06 release decision now authorizes tag, upload and formal Stable publication with explicit 0.4.15 carryover. Matching Quality success and actual artifact verification against the pinned updater key remain mandatory. Official key provenance and Marketplace signed data retain their original status. All 50 items must be verified before claiming full closure. Changelog has 12 sections and exactly one mapping per audit ID; package/Cargo/Tauri/lockfile/README versions agree.
