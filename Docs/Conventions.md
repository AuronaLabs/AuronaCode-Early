# 文档维护约定

文档说明当前行为和边界，帮助读者尽快找到可以执行的下一步。

## 目录与语言

| 位置 | 内容 |
| --- | --- |
| 根目录 `README.md` | 默认英文产品介绍、当前版本、开发入口和语言导航 |
| `Docs/Readme/README.<locale>.md` | 简体中文、繁体中文、日语、德语和意大利语产品介绍 |
| `Docs/README.md` | 英文文档索引，并标明技术指南当前使用的语言 |
| `Docs/Guides/` | 当前使用、安全、本地开发与扩展指南 |
| `Docs/Architecture/` | 当前架构、模块职责与设计原则 |
| `Docs/Development/<version>/` | 当前开发版本的实现、验证结果和待完成事项 |

README 的六种语言保持能力范围、版本和命令一致，使用自然的本地表达。当前技术指南以中文维护；无需把未翻译的文档包装成已翻译内容。旧版本资料通过 Git 历史和系列分支查阅，不在当前目录重复堆叠。

## 事实与格式

- 区分开发状态、正式发布、自动化结果与真实桌面验收。
- 当前行为直接说明，未来方向另行表达，不提前承诺。
- 命令从仓库根目录执行；`tauri:dev` 启动完整桌面，`dev` 只启动前端。
- 应用内更新记录由 `Src/Features/Settings/ChangelogData.ts` 维护，日期与发布状态必须反映实际情况。
- 每篇使用一个一级标题，列表、代码围栏和表格保持格式一致。
- 仓库文件使用相对链接；移动或删除文件时同步更新引用、导航和依赖脚本。

## 检查

```sh
pnpm run check:docs
pnpm run test:docs
git diff --check
```

检查器验证 Git 管理及未忽略的新 Markdown 文件的本地路径、大小写、标题锚点、表格和代码围栏。内容准确性、语言自然度与外部网址仍需人工审阅。
