# Aurona Code 0.3.11 — 材质与氛围

> 0.3.10 让用户「能连续地使用」这些能力；0.3.11 让它们真正好看、可靠、并且不止一种语言可用。
> 本版本围绕两条主线收口：视觉系统从「换个皮」升级为完整的材质与氛围；工程能力从「能用」补成跨平台、可验证、不会只改一半的闭环。

## 主题与背景

- 八套主题各自拥有独立的光域位置、大小、扩散与配色关系——极昼蓝调、绛夜星河、珊瑚落日、薄荷潮汐不再是同一模板换强调色。
- 浅色与深色分别设计氛围，而不是亮度反转；背景由多层径向光场叠加底色渐变组成，编辑器与终端中心保持安静的阅读区域。
- 外观设置中的主题选择器改为真实卡片预览：内嵌渐变圆角矩形、强调色圆点与信息条，选中勾置顶并随深浅色联动。

## Aurona Material

- Panel / Surface / Overlay 玻璃面以 5%–10% 的极轻比例继承主题氛围；浮动层恢复克制的投影，Panel → Overlay → Modal 层级清晰。
- 说明文字、边框与状态色重新校准对比度；成功/警告/错误/信息统一收敛为语义 token，替换散落各处的硬编码颜色。
- 浅色与深色「轻量」材质下，开关开启态提高强调色占比，不再难以辨认。

## 流光

- 流光从「扫过的光带」重做为三个巨大的柔和环境光场，缓慢漂移、轻微呼吸，边缘几乎不可识别。
- 光域颜色直接来自当前主题调色板；运动只使用 transform 与 opacity，开启减少动态效果时保留静态光场。

## 代码智能与工程可靠性

- 跨平台路径模型：file URI ↔ 原生路径按平台统一转换，覆盖 Windows 盘符 / UNC、macOS / Linux、中文、空格与 Emoji，往返语义一致并有测试兜底。
- 多文件修改真正落地：WorkspaceEdit 支持未打开文件，validate → prepare → commit 分阶段执行，整批成功或整批失败，不会只改一半。
- Shift+F12 的引用结果不再被旧 Output 逻辑顶掉；Definition 多结果与 References 共用统一结果视图。
- Problems 支持工作区与当前文件双模式，按文件分组、显示错误/警告数量、点击直达位置，并保持渲染上限。
- 大纲、面包屑与符号搜索共用 Document Symbols 轻缓存，按文档版本失效，LSP 重启与切换工作区自动清理。
- 清理「0.3.2 不支持」这类过期运行时文案。

## 国际化

- 繁體中文 (Beta) 成为正式第三语言，设置内可在简体中文 / 繁體中文 / English (Beta) 间即时切换并持久化。
- 旧的 zh-TW 语言值自动迁移为 zh-Hant，未知或损坏的语言值安全回退默认。
- 关于页、更新弹窗、错误边界、终端、Git、调试、通知与文件资源管理器等区域接入语言包。
- 启动页保持静态 HTML 极轻实现，按语言显示文案，不延迟启动。

## 稳定性与账户

- Aurona Account 网络请求改用系统 TLS（Windows 走 Schannel），修复登录时被连接重置导致「无法连接 Aurona Account」的问题；超时放宽并输出完整错误链。
- 标签页标题统一去掉「打开 / Open」前缀，界面文案清除无用的句末标点。

## 验证与发布标准

- 门禁：typecheck、Biome、桌面/材质边界、smoke、165 前端测试、生产构建、cargo fmt 与 56 项 Rust 测试全部通过。
- 版本：0.3.11（package.json / Cargo.toml / tauri.conf.json / README / SECURITY / Changelog 一致）。
- 发布前人工清单：三平台 CI 构建（Linux 已补充 libssl-dev 依赖）、深浅色与多主题矩阵、macOS/Linux 路径真机验证。
