# Aurona Code 0.3.4 Release Notes

Aurona Code 0.3.4 turns Git from a status summary into an operable project
workflow, rebuilds Fliuno as the unified command and file entry, and makes
right-click, selection, hover, and line operations share one predictable editor
interaction model. Debug sessions gain real frame and variable inspection
instead of a fixed first-frame view.

## Editor interaction

- Right-clicking inside a selection preserves it; right-clicking outside moves
  the caret without beginning a drag.
- Hover anchors are measured from the actual DOM text range that paints the
  token, then clamped and flipped to stay inside the window.
- Opening the context menu cancels pending hover and hides language overlays,
  so two menus can never cover each other.
- Multi-line indent, outdent, line comment, move, duplicate, delete, and
  code-friendly Home/End are committed through one editor snapshot operation.
- Fliuno is the unified entry for commands, recent files, and real workspace
  files, with `>` commands, `@` files, Tab scope switching, and a progressive
  keyboard-first layout.
- The side-bar full-text search remains available; migration to a unified
  search surface is deferred until Fliuno navigation is proven reliable.

## Git Preview workflow

- Source Control moves from Beta to Preview and reuses the existing Aurona UI
  language without exposing internal version badges.
- Local branches can be viewed, created, and switched; tracked branches show
  ahead/behind state.
- Fetch, Pull, and Push are explicit entries and stay disabled without a
  remote; no implicit network operation is performed.
- Staged, unstaged, and untracked files open a Diff, and a confirmed discard
  reverts the selected file.
- Conflict files are grouped separately from ordinary changes, and untracked
  files keep an independent status so they are never confused with conflicts.

## Debug sessions

- Any paused stack frame can be selected and jumps to its source location.
- Variable inspection loads every scope of the selected frame instead of the
  first scope of the first frame.
- Composite values are requested lazily and expand recursively.
- Continue, stop, and adapter exit clear stale frames, scopes, and variables so
  the UI never presents old paused state as current runtime data.

## Architecture and quality

- Pointer hit-testing, overlay positioning, and line operations are pure,
  unit-tested utilities; mutations go through one snapshot operation.
- Git access uses a typed IPC client and argument vectors instead of shell
  interpolation; branch names are validated with `git check-ref-format`.
- The hidden Aurona Account OAuth 2.1/OIDC foundation (PKCE S256, dynamic
  loopback callback, system credential vault) is validated against a local
  provider with real signatures. No login or account entry is shown in 0.3.4.
- Release Notes render as safe Markdown inside the update overlay without
  extra card backgrounds.

## Scope

Task System and the plugin runtime remain deferred; 0.3.4 does not ship fake
task output or unusable plugin entries. Multi-cursor, rectangular selection,
folding, sticky symbols, snippets, stash/rebase/remote-branch operations, Git
graph, watch expressions, variable editing, exception breakpoints, and memory
views are later work.
