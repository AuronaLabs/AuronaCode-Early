## 二、Corona+ 架构符合性

### 已符合项

- **桌面边界**：`@tauri-apps/*` 导入仅存在于 `Src/Foundation/Desktop`；`invokeDesktop/listenDesktop` 仅存在于 `Foundation/Desktop` 与 `Foundation/IPC`（静态脚本 + 人工抽查均通过）。
- **命令单一路径**：标题栏菜单、键盘快捷键（`CommandRegistry.handleKeyDown`）、Fliuno、macOS 原生菜单、拖放入口均走 `CommandRegistry.execute`，未发现绕过点。
- **状态所有权**：工作台/编辑器/终端/调试四个 Zustand store 承担长期状态；EventBus 只做事件，不存业务事实；组件本地 state 用于输入框、浮层、单次请求等短生命周期数据（抽查符合）。
- **事件订阅清理**：`Fliuno`、`useWorkspaceStore`、`AppShell`、`TerminalView`、`EditorTab`、`useFileTree` 等订阅均返回/收集退订函数，未发现泄漏。
- **Features 间解耦**：未发现 Features 之间的直接 import。
- **新文件命令边界**：未提交的 workspace-scoped fs 命令（`workspace_set_root` + `fs_*`）全部走 `State<WorkspaceState>` 授权会话与规范化边界校验，capabilities 已移除 `**` 文件权限，仅保留 `$APPLOCALDATA`/`$APPLOG` 限定权限。

- **性能：highlight.worker 语言裁剪**：Worker 原打包全部 highlight.js 语法（947.3 KB / gzip 305 KB）。0.3.6 改为仅注册编辑器可识别的 7 种语言（rust/python/javascript/typescript/css/json/html），未支持语言直接返回空 token，避免抛错。修复后 Worker 降至 **56.8 KB（约 94% 缩减）**。

- **边界收紧**：`Foundation/Desktop/FileSystem.ts` 移除已无调用方的 `readDir/watch/stat/rename`，导出面只保留 AppLocalData/AppLog 限定操作，与 capabilities 权限一致。
- **复查确认**：PTY/搜索/LSP 会话与请求清理均正确（`close_pty`/`cancel_search`/`lsp_stop_all` 路径完整）；`content_length.rs` 帧解码有头部/消息大小上限；`recover_interrupted_save` 与原子保存恢复路径正确；生产代码无 `unwrap`（仅账户 HTTP 客户端静态配置 1 处 `expect`）与 `any` 类型。
