## 2. URI / Path 跨平台

`Src/Shared/Utils/UriUtils.ts` 现在：

- `uriToPath(uri, platform?)`：Windows 处理盘符、反斜杠与 UNC authority；POSIX 保留原生路径。
- `pathToFileUri(path, platform?)`：Windows 盘符/空格/Unicode/UNC 正确编码；POSIX 原样编码。
- `pathsEqual(left, right, platform?)`：Windows 大小写不敏感、POSIX 大小写敏感。
- `setPathPlatform`：应用启动时由 `AppBootstrapper` 用真实平台同步一次，Utility 层保持零桌面依赖。
- 移除了 `Workspace.tsx` 内一份本地复制的 `fileUriToPath`/`sameFilePath`（遗留分叉）。

测试覆盖（`UriUtils.test.ts`，7 项）：

- Windows：`file:///C:/repo/a.ts` ↔ `C:\repo\a.ts`
- Windows 空格：`file:///C:/repo/my%20file.ts`
- Windows 中文：`file:///C:/repo/测试.ts`
- POSIX：`file:///home/user/repo/a.ts` ↔ `/home/user/repo/a.ts`
- macOS：`file:///Users/user/project/main.ts`
- Round-trip（Windows / POSIX / UNC）
- 中文/Emoji 编码稳定

## 4. WorkspaceEdit

`LanguageFeatureService` 实现：

- **Phase 1 validate**：按文件分组（含同一文件多处 edit 合并）、版本冲突检测、关闭文档磁盘读取、
  预览指纹比对、edit range 校验（`applyLspTextEdits` 已有重叠/越界保护）。
- **Phase 2 prepare**：全部目标在提交前完成内存计算；CRLF 文件插入的 `\n` 自动归一化为 `\r\n`。
- **Phase 3 commit**：已打开文档走 `DocumentService.applyEdits`（版本递增 + LSP didChange + Undo 历史）；
  未打开文档安全写盘并广播 `fs:changed`，不强制打开 Tab。
- **不静默部分成功**：任何校验失败在 Phase 1 抛出；提交阶段失败显式抛出并展示在预览模态中。

新增测试（`LanguageFeatureService.test.ts`，14 项）覆盖：单文件打开、多文件打开、
打开+关闭混合、全部关闭、预览后磁盘变化、版本不匹配、写入失败显式抛出、
中文+Emoji UTF-16 range、同文件冲突版本、resource operation 文案。

## 5. Problems

- `DiagnosticsService.collectProblems(documents, scope, activeFilePath)` 成为唯一摊平/过滤来源。
- 面板新增「当前文件 / 工作区」切换：
  - Workspace：全部诊断、按文件分组显示、文件头带错误/警告计数、点击跳转文件与位置。
  - Current File：保留原有快速过滤，未开文件时显示引导文案。
  - 500 条渲染保护保持不变。
- 生命周期复查：文件删除/重命名（LspClient + useWorkspaceStore 双路径）、关闭标签清诊断、
  工作区切换清空、LSP 重启清语言诊断并重开文档，均已有实现；新增「关闭标签清诊断」回归测试。

## 6. Fliuno / Symbols
