# 0.5.0 Alpha1 实现与验证

记录日期：2026-11-08。内部版本为 **0.5.0-alpha.1**，界面显示 **0.5.0 Alpha1**。本文件记录开发阶段的实现与验证；发布产物和最终发布状态以 GitHub Releases 为准。

## 本轮交付

- 应用 Logo、标题栏、首启引导、启动页、关于页、favicon 及各平台打包图标统一使用新 Aurona 标识，保留原图比例。
- 删除账号页面、头像、命令、服务、IPC、原生鉴权、账号配置、专用依赖和 CI 注入。唯一保留的旧账号标识用于启动时删除旧密钥环凭据，失败时下次启动重试；它不提供登录能力。
- 扩展管理改为已安装列表、搜索、侧栏显示、卸载确认、权限入口与本地导入；支持 .aurx、.vsix 和本地工具链包，工具链服务与共享运行时可卸载。
- 移除商店 UI、远程目录、远程图片、包下载、远程工具链安装接口及服务器源配置。旧扩展包中的可选市场元数据仍可解析，保持本地包兼容。
- 更新记录仅保留 Alpha1。历史开发和发布文档继续作为历史材料保留。
- Agent checkpoint 增加文件不存在状态，支持文本文件新建、删除及重命名两端的恢复；恢复前核对内容、工作区代次和文件类型，未保存编辑拒绝删除。
- 预发布版本比较支持逐段数字与文本排序、Alpha/Beta/RC、正式版优先和忽略 build metadata。
- 本地 .aurx 与工具链包可携带有大小限制的分离签名描述文件；验证固定公钥、有效期、平台及选中内容。VSIX 仍按未认证包处理。

## 后续体验精简

- 全面取消先锋计划：删除高级设置开关、标题标识、运行时渠道状态、专用更新配置与发布分发步骤；现有编辑能力使用统一默认值。
- 用户配置迁移清除旧 `releaseChannel` 偏好，并保留语言、主题等其他设置；迁移可重复执行。
- 文件资源管理器采用 24px 紧凑列表，同步调整虚拟滚动、加载更多、新建与重命名输入行，拖拽反馈不再改变行高。
- 更新记录移除单一版本系列的多余侧栏，搜索并入标题区，正文采用分组排版，减少叠层和亮边。
- 版本介绍首行固定为“当前版本为Aurona Code全新升级的过渡版本”。账号与在线商店移除明确属于阶段性精简，后续将随整体升级重新规划。

本次验证：相关前端 10 个文件的 33 项测试通过，随后补充更新服务回归并复核更新服务及记录数据的 8 项测试，合并去重为 35 项。Rust 库单元测试 205 项通过，包含旧渠道偏好迁移与幂等验证；全目标 Clippy（禁止警告）通过。前端生产构建、全源码 Biome、发布契约、发布元数据 smoke、文档、国际化结构、模块与材质边界检查均通过；修改的发布脚本通过 Node 语法检查。前端按相关文件与补充用例统计，不将中止的整套测试计为通过。

桌面开发预览已核对更新记录的首行文案和分组布局。真实目录展开验收停在工作区访问授权请求，未自动确认；本次没有重编译桌面主程序或生成安装包。

## 明确保留到后续的范围

- 编辑器全文数据流与大文件的进一步改造。
- 多工作区、Agent 长期记忆及上下文压缩。
- 目录树和二进制文件的通用 checkpoint 事务。
- 更广的平台、DPI、IME、故障注入与真实扩展包安装验收。

文本恢复对比和单文件发布不构成跨进程的多文件原子事务。系统钥匙串清理与应用启动、原生安装包验收分别记录，源码检查不替代目标机器上的运行结果。

## 设置、Git 与 AI 助手体验重构

记录日期：2026-11-08。

- Git 页面移除 Preview 徽章，将新建分支、获取远程更新、拉取、推送和恢复记录收进“更多”菜单；保留刷新、分支选择与运行中取消入口。菜单显示待推送和待拉取数量，并在无远程仓库或操作进行中禁用不适用的项目。
- 设置各分类统一标题、说明、分组、设置行的字号、字重与间距，补充窄容器换行规则。AI 设置沿用相同布局与标准选择控件，减少粗体和额外占行。
- 标题栏左上角移除 Logo 图标，保留品牌艺术字。关于页重做品牌、版本信息、更新记录入口、系统信息与开源致谢的层次，减弱光晕和亮边。
- 英文标语统一为“Create Without Limits.”，简体中文为“创造永无止境”，并同步繁体中文、日语、德语和意大利语；首启引导和 README 同步更新。
- AI 助手重做会话入口、消息区、任务状态和输入区。支持自动增高输入框、Enter 发送、Shift+Enter 换行、中文输入法保护、停止任务、运行中追加要求、会话草稿保留、回答复制、工具输入和输出折叠查看，以及上翻后暂停自动滚动和回到最新。
- 发送失败时保留或恢复草稿，避免覆盖后来输入的新内容；最终完整回答覆盖残缺的流式片段。运行中限制会话与模型切换，继续沿用现有权限审批和任务执行服务。
- AI 设置入口可从侧栏直达，并保留尚未挂载的设置页导航目标，避免首次打开时丢失指定分类。
- 品牌字体裁剪为仅包含“Aurona Code”所需的字符（含空格），生成 1828 字节的 WOFF2，内部字体族命名为 Aurona Brand，附带 OFL 许可和可重复生成脚本。主入口与 Splash 都实际预加载并引用该字体。
- 更新记录补充本轮改造，版本仍为 0.5.0-alpha.1，介绍首行保持“当前版本为Aurona Code全新升级的过渡版本”。

## Diff 与文档整理

记录日期：2026-11-08。版本继续保持 0.5.0-alpha.1。

- 源代码管理的“更多”入口只显示省略号图标，保留可访问名称与键盘菜单操作。
- 关于页的系统信息主行仅显示 Windows、macOS 或 Linux，架构与 CPU 核心数合并到下一行。
- 差异查看器改为紧凑工具栏、文件状态、变更统计与正文布局。支持并排和统一视图、自动换行、上一处和下一处变更、手动刷新与失败重试；窄视图自动使用统一布局，恢复宽度后保留原先选择。
- 并排视图按连续修改块配对删除与新增行，只有数量不等的部分保留占位。两侧独立横向滚动，换行后的行高共享，避免左右错位。
- 提取差异解析模型，修复空格路径、Git 转义的中文路径，以及以三个减号或加号开头的代码行解析。展示新增、删除、重命名、复制、二进制、文件属性变化与文件末尾无换行提示。
- 保留原有分块暂存/取消暂存的后端校验，增加前端重复写入保护、过期响应隔离和工作区变化重载。加载完成后重新挂载滚动容器，避免加载占位提前把保留的阅读位置夹到顶部。
- 清理 29 篇旧版计划、审计、验收、发布与归档 Markdown。历史内容保留在 Git 历史和已建立的 0.4.x 分支中；当前指南、架构和 Alpha1 实现记录继续维护。
- 默认 README 重写为英文；简体中文、繁体中文、日语、德语和意大利语版本放在 Docs/Readme/，六种语言相互导航。更新文档索引、贡献与安全入口，整理当前 VS Code 兼容范围，修正旧链接、过期版本和标语。
- 清理 7 个仅服务于旧 0.4.14 文档的审计文件及对应命令、历史范围测试。构建与发布入口改用当前 smoke、文档和发布契约检查；保留匹配提交的 Quality、候选产物来源、固定公钥、签名、哈希与发布审阅流程。
