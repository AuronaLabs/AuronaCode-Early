## 主题：8 × Light/Dark

每套主题在 `Theme.css` 中都拥有独立的：

- `--AmbientFieldA/B/C`：光域颜色、位置、大小、透明度（每套不同，不再是同一模板换色）。
- `--BackgroundBase-*`：底色渐变（浅色/深色各自设计）。
- `--GlassTintRGB`：玻璃面的极轻主题着色（5%–10%）。

## 页面检查

视觉变化主要通过 Material token 全局生效，本轮明确处理了以下高频区域：

- **Editor / Terminal**：新增 `--EditorSurface` / `--TerminalSurface`，内容区保持中性高对比的 Quiet Zone，
  主题氛围只留在外围 Chrome。
- **菜单 / 下拉 / 右键**：浮动层恢复克制的 `--shadow-overlay`，危险项统一 `--StatusError`。
- **通知 / 调试 / 性能 / Git / Diff / 问题 / 语言服务 / 账户**：状态颜色统一收敛到
  `--StatusSuccess / --StatusWarning / --StatusError`（+ 信息沿用 accent）。
- **编辑器搜索**：残留的 `gray-400/500` 按钮色改为 `--color-text-muted`。
- **空态 / 欢迎 / Fliuno / Settings**：依赖语义 token，无需逐个改造（避免 Churn）。

## Contrast 审计

- `TextMuted`：Light 0.45 → 0.54；Dark 0.40 → 0.48（说明文字不再“高级但看不清”）。
- `GlassBorder`：Light 0.04 → 0.06；Dark 0.07 → 0.09（面板分界更清晰）。
- 状态色：Light/Dark 分别给出可读的 Success/Warning/Error 语义值。
- Focus：保留全局 `:focus-visible` accent 描边与 `--focus-ring`，未回退。
- Disabled：沿用 `opacity` + `cursor-not-allowed`，语义 token 未改变该行为。

## 流光（Flowing Light）

旧方案问题：

- 两条斜向 linear-gradient 光带从左/右整体穿越屏幕，明显是“一坨东西在动”。

新方案：

- 三个巨大的圆形径向光域（使用当前主题的 `--RGB-BackgroundGlow-*` 调色板），边缘几乎不可识别。
- 运动仅使用 `transform` + `opacity`，34s/42s/50s 极慢漂移 + 轻微呼吸，不从一边完整穿越到另一边。
- 无 blur 滤镜、无逐帧 JS、无鼠标跟随。
- `prefers-reduced-motion` 下保留静态光场（animation: none + 固定透明度）。
- 配置兼容：继续使用 `data-liquid-texture` 与 `liquidTexture`，无 schema 迁移。
