# Aurona Brand

Wordmark-only WOFF2 derived from Righteous by Brian J. Bonislawsky (Astigmatic).
It contains only the unique characters in **Aurona Code**, including the space.
The modified font is renamed Aurona Brand to respect the reserved font name.
The SIL Open Font License is included in OFL-Righteous.txt.

Regenerate after installing project dependencies and Python fonttools[woff]:

    python scripts/subset-brand-font.py

Use this font only for the wordmark; ordinary UI and version numbers use the
application text and monospace fonts. Main and splash both preload the subset.
